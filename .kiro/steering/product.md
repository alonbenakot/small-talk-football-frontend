# Product: Small Talk Football

Small Talk Football is a web app that helps football (soccer) fans engage more confidently in match conversations. It targets users who may lack deep football knowledge and want to participate in social discussions around games.

## Core Features

- **Matches**: Browse recent and upcoming fixtures with detailed match views (scores, goals, lineups)
- **One-Liners**: AI-generated conversation starters for a given match, tailored by team and language preference
- **Cheat Cards**: Quick-reference "small info" cards organized by category to help users learn football concepts
- **Articles**: Community-submitted articles about football topics, with an admin approval workflow
- **Auth**: User registration and login with role-based access (`MEMBER` / `ADMIN`)

## Language Support

The app supports three language variants for generated content: `BRITISH`, `AMERICAN`, and `HEBREW`.

## User Roles

- **MEMBER**: Can browse content, generate one-liners, and submit articles
- **ADMIN**: Can approve or remove pending articles
